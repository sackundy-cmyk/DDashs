🎯 Learning Objective

Identify and write formulae (rules) that describe the relationship between two sets of numbers

📐 Key Concept: Patterns and Formulae

A formula is a rule written using n — where n represents any number in row A. You apply the formula to n to get the matching value in row B.

How to find the rule:
1. Look at how B changes as A goes up by 1 — this gives you the multiplier.
2. Check what you need to add or subtract to make B match — this gives you the constant.
3. Test your rule with two or more values to be sure!
Example — what is the rule?
A 123 45n
B 246 8102n

B goes up by 2 each time A goes up by 1 → multiplier is 2. When n=1, B=2 = 2×1 ✓ → rule is B = 2n
