🎯 Learning Objective

Compare and order decimal numbers using < and > signs

📐 Key Concept: Comparing Decimal Numbers

To compare decimals, line up the decimal points and compare digit by digit from left to right. Stop as soon as one digit is bigger.

Step 1: Compare the whole number part first (before the decimal point).
Step 2: If equal, compare tenths digits.
Step 3: If equal, compare hundredths digits.
Step 4: If equal, compare thousandths digits.
Example 1: Compare 17.451 and 17.47
17.451 vs 17.47 Tenths: both 4 — equal, go to hundredths
17.451 < 17.47 Hundredths: 5 < 7 — so 17.451 < 17.47 ✓
Example 2: Order 0.933, 0.098, 0.903 smallest first
0.933 vs 0.098 vs 0.903 Tenths: 0 is smallest
0.098 < 0.903 < 0.933 ✓ Answer
💡 Remember: More decimal places does NOT mean bigger number.
0.87 > 0.111 because 8 tenths > 1 tenth — stop there!
< means smaller  ·  > means larger
