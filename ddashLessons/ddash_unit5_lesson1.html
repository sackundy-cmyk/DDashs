🎯 Learning Objective

Use brackets correctly in calculations and understand how bracket position changes the answer

📐 Key Concept: Brackets

Brackets first! Always calculate the expression inside brackets before anything else.
e.g. (4 × 5) + 3 → 20 + 3 = 23  but  4 × (5 + 3) → 4 × 8 = 32

Moving brackets changes the answer — choose carefully!
