📐 Key Concept: Function Machines

A function machine takes a number IN, applies an operation, and gives a number OUT. Some machines have two operations — apply them in order from left to right.

One operation:  IN = 3  →  ×4  →  OUT = 12
Two operations:  IN = 3  →  ×4  →  −1  →  OUT = 11   (do 3×4=12 first, then 12−1=11)
Finding the rule:  Test each option — does it work for ALL values in the table?
