# legacy-html/

This directory contains the **original standalone HTML lesson files** — the source from which the React platform was reconstructed.

These files are kept as permanent reference material. They work independently in any browser with no build step.

## Usage

Open any `.html` file directly in a browser — no server needed.

These files use vanilla JavaScript only (no frameworks, no build tools).

## Why keep these?

- **Fallback**: If the React build fails, these still work
- **Reference**: The original question data, logic, and interaction patterns
- **Archive**: Historical record of how the platform was built iteratively

> ⚠️ **Do not edit these files.** They are read-only archives.
> All new development happens in `src/`.
